# Flutter Expense Tracker

A cross-platform personal finance and cash-flow tracking mobile application built with **Flutter**, **Dart**, and **SQLite (`sqflite`)**.

## Key Features
- **Local Relational Persistence:** Full CRUD expense logging and user account management powered by SQLite (`DatabaseService`).
- **Monthly Cash-Flow & Category Filtering:** Dynamic expense filtering by current month and spending categories (`AllExpensesPage`).
- **Interactive Location Tagging:** Integrated map picker to attach purchase locations directly to expense records.
- **Audio & UI Feedback:** Custom sound effects triggered on transaction logging and state updates.

## Tech Stack
- **Framework:** Flutter / Dart
- **Local Database:** SQLite (`sqflite`, `path`)
- **Features & Plugins:** Interactive Maps integration, Audio playback (`audioplayers`)
